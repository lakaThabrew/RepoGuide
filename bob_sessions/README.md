# Bob Sessions

This directory contains IBM Bob 2.0 session screenshots demonstrating the use of Bob as the core development agent for RepoGuide.

## Required Screenshots

The following Bob session screenshots need to be captured and added to this directory before final submission:

| Filename | Session Description |
|----------|---------------------|
| `01_architecture_design.png` | Bob session designing the RepoGuide architecture and API structure |
| `02_backend_api_implementation.png` | Bob implementing FastAPI route handlers |
| `03_deterministic_intelligence.png` | Bob building the deterministic analysis and Q&A engine |
| `04_security_implementation.png` | Bob implementing path traversal protection and forbidden-file filtering |
| `05_frontend_implementation.png` | Bob building React/TypeScript pages |
| `06_test_suite.png` | Bob writing the 613-test backend test suite |
| `07_final_audit.png` | Bob performing the final pre-submission audit |

## Notes

- Screenshots should be PNG files
- Each screenshot should show the Bob task title and relevant code changes
- Do not include any personal credentials or private configuration in screenshots
- Capture from the IBM Bob 2.0 interface

## How to capture

1. Open IBM Bob 2.0
2. Navigate to the relevant completed session/task
3. Screenshot the task panel showing the work performed
4. Save as PNG with the filename from the table above
5. Add to this directory
